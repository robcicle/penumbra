# **Penumbra**

## **Description**
**Penumbra** is a low-level rendering framework which handles the tasks of Windowing, Input, Rendering Context and Application setup for applications. Users can then focus primarily on their own individual Rendering pipelines and games/projects without worrying about these low-level systems.

## Libraries Used

- [**DirectX11**](https://en.wikipedia.org/wiki/DirectX) – Rendering
- [**spdlog**](https://github.com/gabime/spdlog) – Logging
- [**ImGui**](https://github.com/ocornut/imgui) – Immediate-mode UI
- [**glm**](https://github.com/g-truc/glm) – Mathematics
- [**stb_image**](https://github.com/nothings/stb) – Image loading
